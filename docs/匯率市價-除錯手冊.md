# 匯率 / 市價功能 — 自我除錯手冊

本手冊說明如何自行測試與調整「匯率」與「市價（股價）」自動更新功能，包含測試步驟、要修改的程式位置，以及我檢視程式後判斷的**兩個最可能的問題根因**。

> 重要前提：這兩個功能都需要「能連到外網」的環境。公司內部網路封鎖外部連線，所以**一定要在能上網的環境（例如家中網路）測試**，否則一定失敗。

> 更新（已套用修正）：匯率來源已改為支援新台幣的 `open.er-api.com`；股價查詢已加入「代號自動正規化」（台股自動補 `.TW`）。以下[根因 A/B](#1-先看兩個最可能的問題根因)保留作為背景說明與後續調整參考；若仍有問題，請依第 3~5 節排查。

## 1. 先看：兩個最可能的問題根因

### 根因 A：匯率 API（Frankfurter）**不支援新台幣 TWD**

程式預設 `baseCurrency = "TWD"`（把所有外幣換算成台幣）。但 Frankfurter 這個免費匯率 API 的貨幣清單是以歐洲央行（ECB）為主，**清單裡沒有 TWD**。因此當程式呼叫「把 USD 換成 TWD」時，API 會回傳錯誤或找不到 `rates.TWD`，導致每一筆匯率更新都失敗。

**如何確認**：在能上網的瀏覽器直接打開這個網址，看清單裡有沒有 `TWD`：

```
https://api.frankfurter.app/currencies
```

清單有 USD、JPY、EUR… 但（幾乎可確定）**沒有 TWD**。這就是匯率一直失敗的主因。

➡ 解法見 [第 5 節：修改匯率來源](#51-匯率修改-servicesjs-的-fetchfxrate)。

### 根因 B：股價的「代號」不對 + CORS proxy 不穩

市價功能是用「帳戶/項目」欄位的值當股票代號去查詢。但：

- 你在明細填的是像「`0050 元大台灣50`」「`00631L`」這種**名稱**，不是 Yahoo Finance 認得的**代號**。
- 台股在 Yahoo 需要加 `.TW`（上市）或 `.TWO`（上櫃）後綴，例如 `0050.TW`、`00631L.TW`；美股才是純代號（`QQQ`、`VOO`）。
- 程式透過公開的 `corsproxy.io` 轉發 Yahoo 非官方 API，這個 proxy 有時會擋、有時要求不同用法，**穩定性本來就不保證**。

所以就算連得上網，只要代號格式不對或 proxy 當掉，市價就查不到。

➡ 解法見 [第 5 節：修改股價來源](#52-股價修改-servicesjs-的-fetchstockprice)。

## 3. 如何在電腦上測試（含 DevTools）

### 3-1 啟動本地伺服器

不要用滑鼠雙擊 `index.html`（`file://` 會擋掉部分功能）。請用本地伺服器：

```powershell
cd D:\NCS\mywork_copilot\projects\asset-liability-dashboard
python -m http.server 8765
```

瀏覽器開啟 `http://localhost:8765`。

> 注意：本 App 的 Vue 本身也是從 CDN（unpkg.com）載入。若整台電腦連不到外網，連畫面都不會出現。測試務必在可上網環境。

### 3-2 打開開發者工具（DevTools）

- Chrome / Edge：按 `F12`，切到 **Console（主控台）** 與 **Network（網路）** 兩個分頁。
- 到「明細」頁按「市價/匯率」按鈕，觀察：
  - **Console**：有沒有紅色錯誤訊息（例如 CORS、404、`找不到匯率資料`）。
  - **Network**：找到 `frankfurter.app` 或 `corsproxy.io` 的請求，點開看 **Status**（狀態碼）與 **Response**（回應內容）。
    - Status 200 但沒有你要的欄位 → 資料格式問題。
    - Status 4xx/5xx 或紅色 `(failed)` / `CORS error` → 連線或跨域被擋。

## 4. 如何單獨測試匯率 / 市價函式

不用整個按按鈕，可在 DevTools 的 **Console** 直接呼叫函式，快速定位問題。貼上以下指令後按 Enter：

### 測匯率

```js
// 把 USD 換成 TWD（預期會失敗，因為 Frankfurter 不支援 TWD）
ALD_SERVICE.fetchFxRate("USD", "TWD").then(r => console.log("成功:", r)).catch(e => console.error("失敗:", e.message));

// 改測 Frankfurter 支援的組合（USD -> JPY，預期成功，用來確認 API 本身通不通）
ALD_SERVICE.fetchFxRate("USD", "JPY").then(r => console.log("成功:", r)).catch(e => console.error("失敗:", e.message));
```

- 若第一行失敗、第二行成功 → 證實[根因 A](#根因-a匯率-apifrankfurter不支援新台幣-twd)（API 通，但不支援 TWD）。

### 測股價

```js
// 美股（純代號）
ALD_SERVICE.fetchStockPrice("QQQ").then(r => console.log("成功:", r)).catch(e => console.error("失敗:", e.message));

// 台股（要加 .TW）
ALD_SERVICE.fetchStockPrice("0050.TW").then(r => console.log("成功:", r)).catch(e => console.error("失敗:", e.message));

// 你原本填的名稱（預期失敗，代號格式不對）
ALD_SERVICE.fetchStockPrice("0050 元大台灣50").then(r => console.log("成功:", r)).catch(e => console.error("失敗:", e.message));
```

- 若 `QQQ` / `0050.TW` 成功、名稱那筆失敗 → 證實[根因 B](#根因-b股價的代號不對--cors-proxy-不穩)（代號格式問題）。
- 若全部失敗、Console 顯示 CORS → 是 proxy 被擋，需換 proxy 或改資料來源。

## 5. 如何修改（含替代方案）

### 5-1 匯率：修改 `services.js` 的 `fetchFxRate`

**問題**：Frankfurter 不支援 TWD。

**選項 1（推薦，改用支援 TWD 的免費來源）** — 例如 `open.er-api.com`（免金鑰、支援 TWD、支援 CORS）。把 `fetchFxRate` 改成：

```js
async function fetchFxRate(currencyCode, baseCurrency = "TWD") {
  if (!currencyCode || currencyCode === baseCurrency) return 1;
  // open.er-api.com：回傳「1 個 from 幣別 = 多少各國幣別」
  const url = `https://open.er-api.com/v6/latest/${encodeURIComponent(currencyCode)}`;
  const res = await fetch(url);
  if (!res.ok) throw new Error("匯率查詢失敗 (" + res.status + ")");
  const data = await res.json();
  const rate = data && data.rates && data.rates[baseCurrency];
  if (!rate) throw new Error("找不到匯率資料：" + currencyCode + "->" + baseCurrency);
  return rate;
}
```

> 換任何來源前，先用[第 4 節](#4-如何單獨測試匯率--市價函式)的方式，直接在瀏覽器開該 API 網址，確認 (1) 回得了資料 (2) 回應裡有 TWD (3) 沒有 CORS 錯誤。

**選項 2（最穩，改成手動）** — 若外網來源都不穩，就放棄自動匯率，匯率欄位一律手動輸入（功能其餘部分不受影響）。

### 5-2 股價：修改 `services.js` 的 `fetchStockPrice`

**問題**：代號格式 + proxy 穩定性。

**步驟 A：先把「名稱」對應到「Yahoo 代號」**。建議在明細的「帳戶/項目」直接填正確代號（台股加 `.TW`，例：`0050.TW`、`00631L.TW`；美股純代號：`QQQ`）。

或在程式裡加一層對應表（改 `services.js`，在 `fetchStockPrice` 最前面）：

```js
async function fetchStockPrice(symbolRaw) {
  // 名稱/簡碼 -> Yahoo 代號 對應表（自行擴充）
  const SYMBOL_MAP = {
    "0050 元大台灣50": "0050.TW",
    "00631L": "00631L.TW",
    "00675L": "00675L.TW",
    "QQQ": "QQQ",
  };
  const symbol = SYMBOL_MAP[symbolRaw] || symbolRaw;
  // ...（以下維持原本的查詢邏輯，改用 symbol 變數）
}
```

**步驟 B：若 `corsproxy.io` 被擋，換一個 proxy**。把這行：

```js
const proxied = `https://corsproxy.io/?url=${encodeURIComponent(target)}`;
```

改成其他公開 proxy（擇一測試，穩定性各異）：

```js
// 方案一
const proxied = `https://api.allorigins.win/raw?url=${encodeURIComponent(target)}`;
// 方案二
const proxied = `https://thingproxy.freeboard.io/fetch/${target}`;
```

> 公開 proxy 都可能隨時失效，這是純靜態網站（GitHub Pages 無後端）先天限制。若要真正穩定，需自建一個小型代理服務（例如 Cloudflare Workers），但那超出目前純前端的範圍。

### 5-3 想改基準幣別（例如改用 USD 計價）

改 `js/store.js` 第 22 行附近：

```js
baseCurrency: "TWD",   // 改成 "USD" 等
```

## 6. 如何在 iPhone 上除錯

iPhone Safari 沒有內建 Console，需接電腦：

1. iPhone：設定 → Safari → 進階 → 開啟「網頁檢閱器」。
2. 用傳輸線接上 **Mac**，Mac 的 Safari → 選單「開發」→ 找到你的 iPhone → 選該網頁，即可看到 Console／Network。
3. 沒有 Mac 時：就用本 App 已內建的**畫面錯誤橫幅**（發生例外會在畫面最上方顯示紅色訊息），把訊息截圖即可回報。

- [ ] 股票「帳戶/項目」填的是正確 Yahoo 代號嗎？（台股要 `.TW`）
- [ ] 換過 proxy 後市價是否恢復？
